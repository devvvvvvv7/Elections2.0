Election Controls

Start Voting

Opens the ballot instantly on every Voting PC.

Allow Next Voter

Dismisses the "Thank You" screen on every Voting PC so the next student can vote, without pausing the election.

Stop Voting

Pauses voting. It can be resumed by starting again.

End Election

Permanently locks voting and unlocks results.

Reset Election

Erases all ballots and restores the election to Not Started.
